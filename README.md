# Travel Itinerary App

A travel planning application built using Electron,
HTML, CSS and JavaScript.

## Features
- Weather Search
- Recommended Activities
- Travel Planner
- Food Cost Calculator
- Save, Edit and Delete Activities

## How to Run
1. Download the project.
2. Open the project folder.
3. Open the terminal.
4. Run `npm install`.
5. Run `npm start`.
